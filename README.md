# DB_VIEWER Suite 🚀

A universal, real-time database viewer for **PostgreSQL** and **Microsoft SQL Server**.

## Features
- **Dual Support:** Seamlessly switch between MSSQL and PostgreSQL via UI.
- **Real-time Updates:** Powered by WebSockets (Socket.io) to see data changes live.
- **Dynamic Config:** Configure connections directly in the browser without editing code.
- **SQL Lab:** Run raw SQL queries and see results instantly.
- **CRUD Capable:** Update, Delete, and Create records effortlessly.

## Setup
1. `cd backend && npm install`
2. `cd frontend && npm install`
3. `npm run dev` (from root)

## Security
Sensitive credentials are managed via `.env` files and are excluded from the repository.
